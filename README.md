# Dwarakanath C - Profile

Cinematic portfolio for an AI Engineer and GCP Cloud Developer.

## Stack

React · TypeScript · Vite · Three.js · React Three Fiber · Framer Motion · Tailwind

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The site is static. Deploy the `dist` folder to GitHub Pages, Cloud Storage, or Cloud Run.
